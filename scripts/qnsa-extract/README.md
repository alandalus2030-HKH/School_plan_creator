# استخراج كتالوج QNSA من الوثيقة الرسمية

خطّ أنابيب يحوّل «دليل الاعتماد نهائي.docx» إلى ترحيل SQL يزرع إطار QNSA
بمستوياته الأربعة، ويُنتج معه تقريرَي مراجعة بشريّين.

**لا تحرّر `database/migrations/064_qnsa_final_framework.sql` يدوياً** — هو ناتج
مولَّد. أيّ تصحيح يُكتب في السكربت ثم يُعاد التوليد.

## التشغيل

الوسائط المحفوظة في `work/` تكفي لإعادة التوليد كاملاً بلا حاجة إلى الوثيقة:

```bash
node scripts/qnsa-extract/build_catalog.mjs   # tables.json → catalog.json + flags.json + merges.json
node scripts/qnsa-extract/verify.mjs          # مطابقة حرفية لنصّ كل عقدة مع الوثيقة
node scripts/qnsa-extract/gen_sql.mjs         # → database/migrations/064_qnsa_final_framework.sql
node scripts/qnsa-extract/gen_review.mjs      # → docs/QNSA_CATALOG_REVIEW.md
node scripts/qnsa-extract/gen_html.mjs        # → docs/QNSA_CATALOG_EXTRACTED.html
```

لإعادة التحليل من الوثيقة الأصلية (عند وصول إصدار جديد منها):

```bash
unzip -p "دليل الاعتماد نهائي.docx" word/document.xml > scripts/qnsa-extract/work/document.xml
node scripts/qnsa-extract/parse2.mjs          # document.xml → tables.json
```

`QNSA_WORK=/path/to/dir` يغيّر مجلّد الوسائط إن أردت إبقاءه خارج المستودع.

## الملفات

| الملفّ | الدور |
|---|---|
| `parse2.mjs` | محلّل OOXML بمكدّس — يحترم الجداول المتداخلة ويُخرج `tables.json` |
| `build_catalog.mjs` | يبني شجرة الكتالوج: الملخّص للمستويات 1-3، وجداول المؤشرات للمستوى 4 |
| `verify.mjs` | يتحقّق أن نصّ كل عقدة يرد حرفياً في جداول الوثيقة (يُرجع 1 عند فشل غير مُقرَّر) |
| `gen_sql.mjs` · `gen_review.mjs` · `gen_html.mjs` | المولِّدات الثلاثة |
| `work/tables.json` | الوسيط المحفوظ — خلايا كل جداول الوثيقة بترتيبها |

## عِلل الوثيقة التي يعالجها السكربت

كلّها موثَّقة بتعليق في موضعها من الكود، وكلّ قرار بشري مسجَّل في خريطة باسمه:

1. **ترتيب الأعمدة ينعكس** بين المعيارين 1-2 وما بعدهما → يُقرأ من صفّ الرأس لا بالفهرس الثابت.
2. **علامة التعداد تختلف** بين الأقسام (`•` · `*` · `-`) وتظهر داخل النصّ → تُختار العلامة
   الغالبة في كل خليّة، والشرطة آخر خيار لأنها ترد في قوائم بين قوسين.
3. **أكواد بلا مسافة** بعدها (`5.1.3تنفيذ…`) → المسافة اختيارية في النمط.
4. **عنوان «مجالات التركيز»** يظهر كأنه مؤشر → قائمة منع `LABELS`.
5. **خطأ ترقيم:** «الإدارة الصفية…» = 2.3.4 في الملخّص و2.3.3 في التفاصيل
   → خريطة `RENUMBER` (القرار: 2.3.3).
6. **22 معياراً فرعياً بصياغتين** (ملخّص/تفاصيل) → خريطة `NAME_OVERRIDE` للسبعة المحسومة؛
   الباقي على صياغة الملخّص حتى يُحسم.
7. **فواصل الصفحات تقطع نصّ المؤشر** بين خليّتين — بل تقسم الجدول نفسه إلى جدولين
   → خريطة `JUNCTION`: قرار صريح (`wrap`/`split`) لكل موضع من التسعة. **لا وصل تخميني.**

## ما لم يُستخرج بعد

- مصفوفة تقدير الأداء (ضعيف → ممتاز لكل مؤشر).
- نماذج الأدلة والوثائق لكل جانب.
- الأسماء الإنجليزية (`name_en`) — تنتظر النسخة الإنجليزية الرسمية.
